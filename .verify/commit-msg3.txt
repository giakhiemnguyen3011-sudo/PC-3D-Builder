Drop the premade case models, make the bench reachable, speed up loading

Premade computer case models
- remove the four Case items and delete Completed_Computer_Case_Model
  (69 MB across four files, the largest items on the bench)
- the catalogue is now 31 items and every one of them is installable, so there
  is no longer a carry-only group

Reachable bench
- everything sits on the 0.82 m worktop; there is no under-bench storage
  because a part on a lower shelf is a part the player cannot reach or see
- a longer catalogue now wraps into rows side by side on one surface
  (first-fit-decreasing, so no single long part stretches the bench) instead of
  stacking downwards: 2.38 x 1.10 m, 3 rows, 31 parts
- shelfTier is gone from the data rather than left as a field that lies

Loading
- ModelCache: one parse per file, shared by all five consumers. There were four
  separate GLTFLoaders plus one in HeldItemManager, so a model could be parsed
  4-5 times across different screens; loadModelCopy now returns a clone of the
  parsed scene, which shares geometry and materials
- ShelfHardware seeds a grey stand-in for every part synchronously, then swaps
  in real models as each file lands, so the bench reads as full immediately
- the loading screen now reports real progress and steps aside after the first
  models arrive instead of being hidden instantly
- build-mode thumbnails are baked only for parts the current step accepts, with
  the next step warmed in advance, because toDataURL is a blocking GPU readback
- streaming yields with setTimeout rather than requestAnimationFrame, which
  stops dead in a background tab and would strand the queue half-loaded
