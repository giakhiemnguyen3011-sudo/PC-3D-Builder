Fix hardware orientation, screw clicks, step nametags; allow 3-axis PC rotation

Hardware orientation
- the models were downloaded from many sites and disagree about both axes and
  proportions: the same DIMM ships as 133x3.5x31 mm on one site and
  2085x2017x5017 mm on another. Scaling only the longest edge turned one into a
  53 mm brick and left the next a correct stick, which is what made a RAM stick
  lie flat while another stood up
- hardwareDims.js holds true per-axis dimensions per part type, and
  buildFittedModel now scales per axis, so every variant of a type normalises
  to the same real shape regardless of how its source file was authored
- the scale node now wraps the alignment node rather than sitting inside it, so
  per-axis values land on the aligned axes instead of the file's native ones
- the GPU mount was genuinely wrong: it mapped the 52 mm body thickness vertical,
  laying the card on its side. It is now 313 long into the case, 130 tall, 52 mm
  towards the glass
- mountQuaternion also accepts a full three-edge definition

Screw clicks
- hideScrews and removePart removed their groups from `pivot` while everything
  inside the case is parented to `caseRoot`, so the screw markers were never
  removed from the scene and survived a reset
- hitScrew picked the nearest screw whether or not it had already been driven, so
  one click site emptied the whole pattern. A driven screw is now flagged and is
  no longer a target, and it stays visually driven instead of popping back to
  full size, which made the click look like it had done nothing

Step information
- every step that consumes hardware now names the actual part to look for,
  resolved from the live catalogue so it cannot drift from the model list:
  step 4 -> "Cooler Master Hyper Black Edition", step 5 -> "G.SKILL Trident Z
  RGB 16GB x 2", step 7 -> "Aerocool MasterWatt 650W 80 Plus Bronze"

3-axis rotation
- the finished machine no longer carries noTilt, so pitch and roll work too;
  a mouse only gives two axes, so the scroll wheel takes roll while inspecting
- the pose is remembered when parking and restored on pick-up, so the machine
  no longer snaps upright every time it is put down
- noTilt still applies to a single loose part so it cannot be tipped in the hand
